# Base de Acesso Bibliotecário — Frontend

> Projeto acadêmico em desenvolvimento. Não é uma versão pronta para produção.

Interface web para consulta do acervo e gestão de usuários, empréstimos, reservas e recomendações.

## Stack

- React 19 e TypeScript
- Vite
- TanStack Query e Axios

## Desenvolvimento

```bash
npm install
npm run dev
```

Validações: `npm run lint` e `npm run build`.

Configure `VITE_API_URL` para apontar para o backend e use somente dados fictícios.
